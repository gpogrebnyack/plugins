# Lansy LinkedIn Studio

Пост собирается из шаблонов Lansy Studio через инструменты `lansy_*` этого плагина. Движок студии сам ставит кегли, отступы, пальму, номера страниц и lansy.ai; агент выбирает шаблон, вариант и пишет тексты. Ничего не рисуется руками, координат нет.

Пост с одной картинкой — это карусель из одной страницы: всё ниже работает так же.

Результат — ссылка на пост в студии. Пользователь дотюнивает её там: двигает кадр фото, меняет картинки, правит слова.

## Инструменты

| Инструмент | Зачем |
|---|---|
| `lansy_catalog` | Шаблоны, варианты, какие картинки берёт вариант, поля, библиотеки фото, иконок и экранов. Читай один раз за задачу, до первой страницы |
| `lansy_check` | Проверка без сохранения: ошибки, что не влезло и сколько знаков влезет, размер заголовка L/M, пустые картинки |
| `lansy_create` | Сохраняет пост, возвращает ссылку, `id`, `updated_at` и id страниц |
| `lansy_get` | Без id — список постов. С id или ссылкой — страницы, `updated_at`, отчёт |
| `lansy_update` | Правка поверх прочитанной версии. `pages` — весь новый список |
| `lansy_upload_image` | Картинка с диска в библиотеку пользователя → путь для `img`, `cut` или `uiImg` |

Инструмент пишет «No Lansy token», «isn't a token» или «token was refused» — скажи пользователю: «Создай токен в Lansy Studio → меню аккаунта → Agent access и впиши его командой /plugin configure lansy-linkedin-studio@gpogrebnyack». Дальше не продолжай.

## Запреты

- **Факты — только от пользователя.** Цифры, имена, должности, города, названия клиентов, цитаты — дословно из его текста. Нужна цифра, которой нет, — спроси. Не выводи «шаги» и «советы» из одного факта: такую страницу не делай или спроси.
- **Клиент без согласия — без имени.** Названа компания-клиент — спроси, согласована ли публикация имени. Нет ответа или нет согласия — «a hotel group», «a coffee chain».
- **Позиционирование:** Lansy превращает живые разговоры с клиентами в советы сотрудникам и инсайты для бизнеса. Веди от анализа разговоров и обратной связи персоналу. Прямо рост выручки не обещай: «revenue grew» — только если это факт пользователя, и подавай его как результат разговоров, а не обещание.
- **Тексты на страницах — только по-английски.** Отчёт пользователю — на его языке.
- **Людей не генерировать.** Человек на странице — только присланный пользователем вырез (`cut`) или фото. Образец бариста, которым студия заполняет пустой блоб и аватар, в готовый пост не попадает (см. «Картинки»).
- **Маркер** `*фраза*`: одна фраза из 1–3 слов на текст, на словах со смыслом. Никогда на цифрах, никогда весь текст, только в полях с `marker: true`. Не на каждой странице: на 2–4 страницах карусели, где текст несёт всё сообщение (заявление, цитата, обложка).
- Не обходить ошибки API: ошибка — значит, правило бренда. Исправляй текст или шаблон.

## Процесс

### 0. Вход
Возьми из запроса; спроси только то, без чего нельзя:
1. **Идея** — одна мысль, ради которой пост.
2. **Факты** — цифры с единицами и источником (пилот, сколько точек, срок), цитаты с именем и ролью. Фактов нет совсем — спроси, не начинай.
3. **Картинки** — пути к файлам: вырез человека (PNG без фона), фото, скриншоты. Нет — работай с библиотекой.
4. **Формат** — карусель (по умолчанию 5–7 страниц) или одна картинка. Одна мысль и одна цифра или цитата — предложи одну картинку.
5. **Тема** — `lime` по умолчанию, `green`, если попросили.

### 1. Каталог
`lansy_catalog`. Из него — какие поля у шаблона и какие картинки берёт каждый вариант. Не угадывай имена полей.

### 2. Раскадровка
Нарежь историю: одна мысль — одна страница. Выбери шаблон по мысли:

| Мысль | Шаблон |
|---|---|
| Вход в историю, отрасль, тема | `cover` (Picture). Full — фото на весь кадр; Above/Below — картинка сверху или снизу. Чип отрасли `tag` |
| Вывод, заявление, поворот | `thought` (Statement) |
| Одна цифра, на которой держится пост | `number` (Big number): `num`, подпись `h`, источник `src` |
| 2–6 сравнимых значений с единицами | `chart` (bars, cols, ring) |
| Что именно видит сотрудник или владелец в Lansy | `product`, экран из `screens` |
| 2–6 пунктов: находки, шаги — только из фактов | `list` |
| Слова реального человека | `quote`: Card — с вырезом человека в аватаре; Full — на фото |
| Знакомство с человеком из кейса | `person`: вырез в блобе или фото |

Ритм:
- Первая страница — `cover` или `thought`. Последняя — вывод (`thought`) или что делает Lansy (`product`).
- `thought`, `number` и `quote` Card стоят на цветном фоне темы. Больше двух таких подряд нельзя: между ними — страница на светлом фоне (`list`, `chart`, `product`, `cover` с 3D или экраном) или фото.
- Один шаблон два раза подряд нельзя. Цифры одного ряда (одна единица и одна база: доли от одного целого, значения по часам или точкам) — один `chart`, а не два `number`. Цифры с разной базой («предложили в 21% заселений», «из них согласились 34%») на одну шкалу не ставь: разведи их другими страницами.
- Каждая страница несёт своё: фото, 3D, интерфейс, данные, человек. Не четыре интерфейса подряд.
- 3D-иконка — одна на страницу, отрасль совпадает с кейсом, иконки в карусели не повторяются. Фото из библиотеки — не больше одного одинакового.

Одна картинка: страница должна держаться сама. Бери `number` (цифра + подпись + источник), `thought` (заявление), `quote` (цитата с человеком) или `cover` с картинкой и чипом отрасли. Маркер — на ней, ритм не нужен.

### 3. Тексты
- Пиши сразу коротко: заголовок 3–7 слов. Большие шаблоны ставят заголовок в L (15%), только если он влезает; длинный уходит в M (11%). Отчёт `lansy_check` скажет, сколько знаков влезет в L.
- `|` — перенос строки, нужен в основном в `name` («Maria Lopez,|*still curious*»).
- Подпись к числу объясняет число одной фразой, без маркера. `src` — откуда цифра: «Lansy pilot · 8 hotels, 3 months».
- Цитата — без кавычек, страница ставит их сама. `author` и `arole` — имя и «роль, город».
- Не повторяй заголовок обложки на других страницах.

### 4. Картинки
- Файлы пользователя — через `lansy_upload_image`. Ответ `transparent` — вырез человека: в `cut` (блоб, аватар). `opaque` — фото: в `img`; скриншот интерфейса — в `uiImg`.
- Нет выреза человека — не бери `person` с блобом и `quote` Card: студия поставит туда образец бариста. Бери `quote` Full с фото или `thought`. Голый блоб — `noPerson: true`.
- Фото из библиотеки — ключ из `photos`, по отрасли кейса.
- Экраны из `screens` показывают разговоры кафе и магазина. Бери их только для кафе и ритейла. Для другой отрасли — скриншот пользователя (`uiImg`) или страница без интерфейса: экран про сумки в посте про отели читается как подлог.
- Пустой слот фото допустим, только если пользователь сказал, что добавит фото сам. Отметь в отчёте.

### 5. Проверка
`lansy_check` со всеми страницами. Не больше трёх кругов:
- **Ошибки** (✗) — исправь все: поле, маркер, вариант, картинка.
- **Не влезает** (`Fits: NO`) — сократи то поле, которое назвал отчёт, до указанной длины. Не меняй шаблон ради длинного текста.
- **Headline is M** — если сокращение не портит смысл, сократи до L. Нет — оставь M.
- **Пустая картинка / образец бариста** — исправь по пункту 4 или вынеси в отчёт.
- Info про три одинаковых шаблона подряд — перестрой ритм.

### 6. Сохранение
`lansy_create` с `title` — коротко по теме, его видно в списке студии. Сохрани `id` и `updated_at` из ответа: они нужны для правок.

### 7. Отчёт пользователю
- Ссылка на пост — первой строкой.
- Таблица: `№ | шаблон | мысль`.
- Что доделать руками в студии: фото, кадрирование, места, где взят образец.
- Допущения: что сокращено, что отложено из-за нехватки фактов.

## Правки
1. `lansy_get` с id или ссылкой — прямо перед правкой: пользователь мог поменять пост в студии.
2. `lansy_update` с `base_updated_at` из этого ответа. `pages` — **весь** список по порядку: `{ "id": "…" }` оставляет страницу как есть со всем, что пользователь настроил в студии; `{ "id": "…", "h": "…" }` меняет поле; страница без `id` — новая; не перечисленная — удаляется. Только название или тема — без `pages`.
3. Ответ «changed since you read it» — снова `lansy_get` и повтори правку поверх новой версии. Не затирай правки пользователя.

## Текст поста
Только если попросили. Английский, от «we»: простая история, абзацы по 2–3 предложения, без афоризмов. Не начинай со строки, повторяющей заголовок обложки, — начинай с первого предложения истории. Без хвостов вроде «Here's what it looks like» или «We'll keep sharing»: текст кончается последним фактом.
